# Anchor Improvements

**Features**
- Anchors can now be thrown
- Adds text to winch showing how much rope is currently out.
- Doubles the length of anchor rope.

**Options**
 - Winch info
	- Shows how many yards of rope are out when looking at anchor winch
	- Disabled when SailInfo is installed
 - Anchor fixes
	- Fixes held anchor pulling boat. 
	- Fixes unpurchased anchors saving position. 
	- Fixes Jong anchor starting position
	- Disabled when NANDfixes is installed
 - Resize brig anchor
	- Doubles the size of the brig's anchor and windlass
	- Requires a reload to take effect (i.e. won't update immediately when toggled from the Configuration Manager menu)
